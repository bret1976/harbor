# Harbor

Local studio for image and video. Prompts, characters, and stories live in the app. Generation runs on an Apple silicon Mac, where the models are installed.

On this Mac, double-click `Harbor.command` on the Desktop, or run:

```
node server.mjs
```

Then open http://127.0.0.1:3340.

The hosted copy is the same studio. It does not download or run the models.
